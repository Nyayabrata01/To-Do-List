# 📝 To-Do List – HTML, CSS & JavaScript

A simple, user-friendly To-Do List web application built using **HTML**, **CSS**, and **JavaScript**. This app allows users to manage their daily tasks efficiently with features like adding, deleting, and marking tasks as completed. It also uses `localStorage` to persist tasks across sessions.

## 🚀 Features

- ✅ Add new tasks
- ❌ Delete tasks
- ✔️ Mark tasks as completed
- 💾 Save tasks to browser localStorage
- 📱 Responsive and clean UI

## 🧰 Tech Stack

- **HTML5** – Structure and layout
- **CSS3** – Styling and responsiveness
- **JavaScript** – Logic and interactivity
- **localStorage** – Persistent data storage in the browser
